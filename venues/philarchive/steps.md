# PhilArchive：投稿の手順

利用者が手順を求めたので、手順として書きます（cpsbvbng26-dotcom の決めごと 16 の例外）。
独身論の続編のために作った手順（2026-11-18）を、作品によらない形にしたものです。
PhilArchive の案内の頁は、この作業の環境から取り寄せられませんでした。
画面の名前とボタンの名前は、どの段も記憶によります。
欄に貼る文は [fields.md](./fields.md) にあります。

1. PhilPapers のアカウントで PhilArchive にサインインする。前の論文を出したときのアカウントを使う。
2. 投稿の入口（Submit / Archive a paper）を開く。
3. 種類（Pub type）に、査読前の原稿を選ぶ。
4. 題、著者、要旨、キーワードを写す。所属は書かない。機関の名は、どの欄にも書かない。
5. 分類を選ぶ。名は philpapers.org の分類の頁で確かめたものを使う。上限に当たったら、主と副を優先する。
6. 識別子の欄に、先の場が出した DOI を写す。まだ出ていなければ、ここで止めて、出てから続ける。番号を推測で書かない（決めごと 1）。
7. 関連の欄や注記の欄があれば、関連する論文を挙げる。
8. PDF を上げる。
9. ライセンスを選べる場合は CC BY 4.0 を選ぶ。
10. 確認の画面で、題・要旨・分類・識別子・PDF を見直し、送る。
11. 載ると、記録の ID（NEMTNA のような形）が出る。その ID だけを記録に書く。PhilArchive は DOI を発行しない。
